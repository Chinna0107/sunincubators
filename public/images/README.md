Drop all official Instagram images (@sunincubators) into the folders below.
Images will appear automatically — no code changes needed.

## Notes
- Any image format works: .jpg, .jpeg, .png, .webp
- Recommended min size: 800×600px for products, 1200×800px for hero
- Images will display with aspect ratios as configured (no stretching)
- If an image file is missing, the placeholder is shown automatically
